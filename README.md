# Random Password Generator
A simple Python project that generates a random password based on the length entered by the user. This project uses Python's built-in `random` and `string` modules to create passwords containing uppercase letters, lowercase letters, and numbers.
## About the Project
This project was created as part of my Python Programming Industrial Training at DecodeLabs. The main aim of this project is to understand how Python libraries work and how random passwords can be generated using programming.
## Features
* Generates a random password instantly.
* User can choose the password length.
* Uses uppercase and lowercase letters.
* Includes numbers in the password.
* Easy to understand and beginner-friendly.
## Technologies Used
* Python 3
* Visual Studio Code (VS Code)
## Python Modules Used
* `random`
* `string`
## How to Run
1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the `password_generator.py` file.
5. Enter the password length.
6. The generated password will be displayed on the screen.
